## Neotrix System v1.8.4

- Read and write file comments inside Explore Project Files, without closing the browser or opening a separate dialog.
- Scroll discussion history, refresh shared comments, edit multiline drafts and post with Ctrl+Enter.
- Share schema 1 JSON comments with Neotrix Prism and its Blender, Fusion and After Effects integrations; preserve existing Blender comments.
- Allow Quick Render for any saved Blender file, including mapped drives and UNC paths, independently of the browser root.
- Preserve shot-based render destinations and provide adjacent RENDERS folders for ordinary saved files; version suffixes are optional.
- Retain cached browser filters from the v1.8.3 startup-freeze repair.

### Install

Download Neotrix_System_v1.8.4.zip and install it through Blender Preferences → Add-ons → Install from Disk. Enable Neotrix System and open the Neotrix sidebar.

Tested with Blender 5.2.1 LTS on Windows. Shared comments use JSON sidecar folders; this release does not install a Windows Properties extension. Default project browsing expects Neotrix folder conventions.
